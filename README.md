# Task 6: Static Website with GitHub Pages

A simple HTML and CSS site for the DevOps internship. This is a separate project from Task 4 (`devops-git-project`).

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a separate public GitHub repository for this project.
2. Push the `main` branch.
3. In repository Settings → Pages, select Deploy from a branch, `main`, and `/(root)`.
4. Open the published URL shown by GitHub Pages.
