My first static website

This site is built with HTML and CSS, then published with GitHub Pages.

About this project

GitHub Pages serves these static files directly from the project repository, so no running EC2 server is needed.

How it was published

  1. Create an index.html file.
  2. Push the project to its own GitHub repository.
  3. Enable GitHub Pages from the main branch and root folder.

A small static site, available on the web over HTTPS.
